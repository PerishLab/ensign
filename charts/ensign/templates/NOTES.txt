Read the genesis sudo token out of the api log. It is minted and printed once,
on first install, and is never re-minted:

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ .Release.Name }}-api \
    | grep 'keel: sudo token' | awk '{print $NF}'

Do this now. If the api pod restarts first the line is gone from the current
log; `--previous` reaches one restart back, and past that the token cannot be
recovered without a fresh store.

Reach the web UI through the ingress host:

  {{ if .Values.ingress.enabled }}{{ if .Values.ingress.tls }}https{{ else }}http{{ end }}://{{ .Values.ingress.host }}/{{ else }}(ingress disabled — port-forward svc/{{ .Release.Name }}-web:80){{ end }}

The sudo token is the one pre-identity axiom — use it once to seed your
first admin grants, then rely on operator faces.
